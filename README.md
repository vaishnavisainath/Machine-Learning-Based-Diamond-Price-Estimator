# 💎 Machine Learning-Based Diamond Price Estimator

This project is focused on predicting the price of diamonds using machine learning. It includes data cleaning, visualization, feature encoding, and the implementation of a linear regression model using NumPy.
## 📂 Dataset

The dataset used is `diamond.csv`, which includes the following features:

- `carat`
- `cut`
- `color`
- `clarity`
- `price`

## 🛠️ Tools & Libraries

- Python
- Pandas
- NumPy
- Seaborn
- Matplotlib
- Plotly
- Linear Regression (manual implementation)

## 🔍 Project Highlights

- Handled missing values and duplicates
- Encoded categorical features numerically
- Normalized and scaled the dataset
- Visualized data distributions and correlations
- Implemented linear regression from scratch using matrix operations
- Evaluated model performance using Mean Squared Error (MSE)
- Visualized predicted vs. actual prices

## 📈 Output

The model was able to predict diamond prices based on features like cut, clarity, color, and carat, and visualizations demonstrated the relationship between predicted and actual values.
